- やったこと：採点のモデルだけを変えて再実行した。既定の gemini-3.5-flash-lite から、AIE_MODEL=gemini-3.5-flash に切り替え、同じ labels.jsonl と直した後の rubric.md で `uv run python -m app.judge` を実行した（他の条件は変えていない）
